# دليل تشغيل لوحة تحكم الأدمن (Admin Dashboard) ونظام عزل حسابات العملاء

تم بناء وتفعيل **لوحة تحكم إدارية كاملة (Web Dashboard)** تتيح لك إدارة جميع المشتركين بصرياً من المتصفح، مع **نظام عزل الحسابات (Multi-Tenant Isolation)** بحيث يكون لكل عميل بياناته وحساباته الإعلانية المستقلة دون أي تداخل.

---

## 1. كيفية فتح لوحة تحكم الأدمن (Admin Dashboard)

1. تأكد من أن السيرفر يعمل (محلياً أو على VPS).
2. افتح المتصفح على الرابط:
   👉 **`http://localhost:2222/admin`**
   *(أو على رابط الـ VPS الخاص بك مثل `https://mcp.yourdomain.com/admin`)*
3. سيطلب منك المتصفح مفتاح الأدمن السري (**Admin Key**):
   * المفتاح الافتراضي: **`admin123`**
   * (يمكنك تغييره في أي وقت من ملف `.env` عبر متغير `ADMIN_SECRET`).

---

## 2. ميزات لوحة تحكم الأدمن (Admin Panel Features)

من خلال اللوحة يمكنك القيام بكل ما يلي بنقرة زر واحدة:

* **📊 إحصائيات فورية (Realtime Stats):**
  * عدد المشتركين الإجمالي.
  * عدد الاشتراكات النشطة حالياً.
  * الاشتراكات التي ستنتهي قريباً (أقل من 7 أيام) لتتواصل معهم للتجديد.
  * عدد العملاء المتصلين الآن مباشرة عبر Antigravity (Live Sessions).

* **➕ إضافة مشترك جديد مع عزل الحسابات (Add Isolated Client):**
  * **اسم المشترك:** (مثلاً: "متجر سفيان").
  * **مدة الاشتراك:** (مثلاً: 30 يوماً).
  * **معرف الحساب الإعلاني (Ad Account ID):** يحدد الحساب المخصص له فقط (مثل `act_123456789`).
  * **Facebook Token الخاص به:** تضع التوكن الخاص بحسابه الشخصي، ليرى إعلاناته وحملاته هو فقط.
  * **ملاحظات:** (مثل تفاصيل الدفع والتحويل).

* **⚡ تجديد بنقرة زر (+30 يوم):**
  * زر سريع لكل عميل لتمديد اشتراكه 30 يوماً إضافية بمجرد استلام التحويل.

* **📋 زر نسخ إعداد Antigravity جاهزاً:**
  * بالضغط على زر **"📋 كود AI"** بجانب أي عميل، يظهر لك كود الـ JSON جاهزاً ومخصصاً لهذا العميل لترسله له ويضعه في Antigravity.

* **⏸️ إيقاف مؤقت / تفعيل:**
  * إذا تأخر في الدفع، تضغط على زر الإيقاف المؤقت، ويتم قطع اتصاله فورياً في نفس اللحظة حتى لو كان وسط شات.

* **✏️ تعديل وحذف:**
  * تعديل التوكن أو الحساب الإعلاني أو حذف العميل نهائياً.

---

## 3. كيف يضمن النظام عزل بيانات كل عميل بنسبة 100%؟

عندما يتصل أي عميل من تطبيق **Antigravity** الخاص به:
1. يقرأ السيرفر كود الترخيص الخاص به (`Bearer meta_sec_...`).
2. ينشئ السيرفر له **جلسة MCP مستقلة ومعزولة تماماً في الذاكرة**.
3. يستخدم السيرفر حصراً الـ `Facebook Token` والـ `Ad Account ID` المخصصين لهذا العميل فقط.
4. أداة `meta_get_assigned_account` تزود Antigravity تلقائياً بمعرف حسابه، فلا يستطيع قراءة أو تعديل أي إعلان أو حملة تابعة لعميل آخر.

---

## 4. تجربة الاتصال الخارجي عبر ngrok مع لوحة التحكم

1. شغل في نافذة موجه الأوامر:
   ```bash
   ngrok http 2222
   ```
2. ستحصل على رابط مثل: `https://xxxx.ngrok-free.app`
3. يمكنك فتح لوحة التحكم من هاتفك أو أي جهاز خارجي عبر:
   `https://xxxx.ngrok-free.app/admin`
4. ورابط الربط مع Antigravity للعملاء سيكون:
   `https://xxxx.ngrok-free.app/sse`
